# Release Notes v0.3

Initial public cleanup release.

## Public Boundary

- Public workflow ends at Unified Case Report.
- Optional public summary helper generates a Reddit technical post template.
- No original videos, generated heavy outputs, local paths, secrets, local configs, or private publication assets are included.

- Python forensic lab modules for tracking, dynamic ROI, motion, spectral, thermal/IR, controls, PCA, autoencoder, SRV, unified reports, and Reddit template generation.
- Electron desktop cockpit with `Public Summary` instead of a publication/content automation tab.
- Public safety scanner.
- Source-available non-commercial license.

## Excluded

- Private publisher/content automation.
- Generated content packs.
- Social platform captions, tags, or publication clips.
- Local private datasets and reports.
