# Private Modules

Content Pack / Publisher Pack is private-local-only and not part of the public release.

The public release stops at:

1. Unified Case Report
2. Public Summary / Reddit Technical Post Template
3. Local evidence/review video assembled from existing technical outputs with a no-origin-claim notice

Private local workflows may exist outside this repository for preparing captions, platform metadata, promotional derivative clips, or publisher-oriented assets. Those workflows are excluded from the public release and should not be treated as part of the source-available project. The technical evidence-video exporter is not a publisher workflow and does not upload or publish anything.

Do not publish private media, generated content packs, local reports, local paths, social metadata, or automation credentials.
