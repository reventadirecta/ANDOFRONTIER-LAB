# Run AndoFrontier Lab on Windows

## Quick Start

1. Download `AndoFrontier-Lab-v0.3-Windows.zip` from GitHub Releases.
2. Unzip it to a normal folder, for example `Documents\AndoFrontier Lab`.
3. Run `AndoFrontier Lab.exe`.
4. Click `Import Video`.
5. Select a local video file.
6. Draw a box over the object in `Video & Tracking`.
7. Run tracking.
8. Validate the track.
9. Run analyses.
10. Generate Unified Case Report.
11. Generate Public Summary if needed.

## Important Notes

- No videos are included.
- Outputs are generated locally on your machine.
- Source quality matters.
- The app does not make origin claims.
- The app is not a proof engine.
- Public summaries are technical templates for review, not automatic publication.
